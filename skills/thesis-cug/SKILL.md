# 毕业论文格式助手（骨架）

> ⚠️ 本技能尚未录入具体格式规范。**触发时应先向用户索要格式文件**（学校研究生院/教务处模板 docx、格式要求 PDF），拿到后把规范录入本文件并删除本提示。

## 用户触发时先做

1. 询问是否有学校官方模板或格式要求文件，请用户提供
2. 若用户提供，提取格式规则写入本文件"格式规范"一节
3. 若用户暂无文件，按用户口头要求执行，并提醒结果需按官方模板校对

## 待录入的格式项清单

- [ ] 页面设置：纸张、页边距、页眉页脚、页码
- [ ] 封面/声明页要求
- [ ] 标题层级：各章/节标题字体、字号、编号格式
- [ ] 正文：字体字号、行距、段前段后、首行缩进
- [ ] 图：编号规则（图 x-x）、图题位置与字体、插图规范（→ figure-visio / figure-origin）
- [ ] 表：编号规则（表 x-x）、三线表要求、表题位置
- [ ] 公式：编号格式、缩进
- [ ] 参考文献：标准（GB/T 7714）、著录格式、文中引用样式
- [ ] 中英文摘要与关键词格式
- [ ] 致谢、附录、攻读学位期间成果格式
