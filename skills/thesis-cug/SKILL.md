# 中国地质大学（武汉）研究生学位论文格式

依据：研究生院《中国地质大学（武汉）研究生学位论文写作规范》（2025年5月版，官方原文见 `references/cug官方文件/`）。**执行冲突时以官方 .doc 原文为准**；本文件是速查提炼。

## 论文结构（16部分，依次排列，每部分另起页）

中文封面 → 中文题名页 → 英文题名页 → 原创性声明 → 导师承诺书 → 使用授权书 → 作者简介 → 答辩委员会名单（置于中文摘要之前）→ 中文摘要 → Abstract → 目录 → 图和表清单（如有）→ 正文 → 参考文献 → 致谢 → 附录

- 字数：博士 ≥5 万字，硕士 ≥3 万字（各学科可另规定）
- 学校代码 10491；论文题目 ≤25 字，可加副标题；日期用汉字（二〇二五年五月），不用阿拉伯数字

## 页面设置

A4（210×297mm）；上下 3cm、左右 3cm；页眉 2.5cm、页脚 2.0cm；装订线 0cm

## 页眉与页码（第1章起至最后）

- 奇数页居中：`中国地质大学□`（□ = 博士学位论文 / 硕士学位论文 / 硕士专业学位论文(全日制)/(非全日制) 等，按学生类别）
- 偶数页居中：`作者姓名：论文题目`
- 宋体 10.5 磅（五号），页眉下有下划线；Abstract 部分用 Times New Roman 10.5 磅
- 页码在外侧，从第一章起 1, 2, 3… 连续编排

## 层次标题与正文（表3.8 核心排版）

| 元素 | 格式 |
|---|---|
| 章标题 `第一章 ×××` | 黑体 16磅（三号）加粗居中，单倍行距，上下空 2 行 |
| 一级节 `1.1 ×××` | 黑体 14磅（四号）加粗居中，单倍行距，上下空 1 行 |
| 二级节 `1.1.1 ×××` | 黑体 12磅（小四）居左，单倍行距，上下空 1 行 |
| 正文段落 | 宋体 12磅（小四），英文 Times New Roman 12磅，两端对齐，首行缩进 2 字符，**固定行距 20磅**，段前段后 0 |
| 各章标题序号 | 序号与题名间空 1 个汉字符；末位数字后不加点（`3.1.2`） |

## 图、表、公式

- **图**：分章编号 `图3.2`，图题居中置于**图下方**，宋体 10.5磅（五号），序号与图题空 1 汉字符；先见文字后见图
- **表**：分章编号 `表3.1`，表题居中置于**表上方**，宋体 10.5磅；**三线表**；转页续表重复表头，标"(续)"
- **公式**：分章编号 `(3.2)` 圆括号，Times New Roman 10.5磅右对齐；转行在 `＝ + － × /` 处；表达式另行起排缩格书写
- **插图制作**：一律走 `academic-figure-style` 技能（Origin 数据图 / Visio 示意图，宋体+Times、量斜体单位正体——与官方 2.7 条一致）

## 量与单位（GB 3100~3102—1993）

- 量符号单个拉丁/希腊字母，**一律斜体**（pH 例外）；角标区分情况
- 单位用国际符号**正体**，数值与单位间留空隙
- 坐标轴标题"量 / 单位"斜杠分隔（详见 academic-figure-style 的 typography-rules）

## 摘要与关键词

- 中文摘要：第三人称、不加评论，含目的/方法/成果/结论，以 1 页为宜；不得出现图表、方程、非公知符号
- Abstract：与中文对应，≥300 英文实词，1 页为宜；留学生英文论文的中文摘要 ≥6000 字
- 关键词 3~5 个，分号分隔，另起一行；尽量用《汉语主题词表》规范词
- 排版：标题黑体/Times 18磅（小二）加粗居中；文字宋体/Times 12磅（小四）固定行距 20磅；"关键词"/"Key Words"加粗

## 参考文献（GB/T 7714—2005）

- 顺序编码制（正文上标 `[1]`，多处 `[2-3]`，页码 `[1]198`）或著者-出版年制，**全文统一**
- 作者 ≤3 位全列，>3 位列前 3 位加"，等"
- 著录格式：专著 `[序号] 作者.书名[M].出版地：出版者，年：页码.`；期刊 `[序号] 作者.文题[J].刊名，年，卷(期)：页码.`
- 私人通信、未公开资料不入参考文献表，当页脚注

## 目录排版

标题"目录"黑体 16磅加粗居中；章条目宋体 14磅（四号）、节 12磅（小四），固定行距 20磅，页码右对齐，一级/二级节分别左缩进 1/2 汉字符

## 印刷装订

- 中文摘要起**双面印刷**，之前部分单面
- 线装或热胶装，**禁止金属钉装订**
- 书脊：仿宋，上题目、中作者、下"中国地质大学（武汉）"

## 工作流建议

1. **新建论文**：直接用官方附件（声明/授权书等在 `附件1-11.doc` 里是现成文本，不要手打）
2. **写作中**：按上表排版；每章完成即自查
3. **定稿前**：过一遍学校**格式检测**（研究生院通知页选对应模板上传）
4. 用户给的是其他类型（本科/课程）→ 见下

## 边界

- **本科毕业论文**：教务处《学士学位论文写作规范（2018版）》+ 论文格式模板（https://bksy.cug.edu.cn/info/1489/1851.htm ，下载有验证码需浏览器手动），不要套用研究生规范
- **期刊投稿**：用 `paper-cn-journal` 技能
- **插图**：用 `academic-figure-style` 技能
