# Origin 论文出图格式（点线图，以 7cm×5cm 为例）

来源：用户提供的 `origin论文出图格式.docx`。下列数值为规范原文，执行时直接照抄数值，不要"取一个大概"。

对应截图：`assets/origin-01-page-size.png` … `assets/origin-07-export.png`。

> ⚠️ **本机 Origin 2025b 的两点注意**
> 1. 当前 Origin 未激活，导出带 "demo" 水印，不能投稿（见 [automation-stack.md](automation-stack.md)）。
> 2. Origin 2025b 改了**图页比例、边距、字体呈现、轴框、线宽、刻度标签自动旋转**的默认值。
>    本规范原文可能出自更早版本，在 2025b 上要重新核对视觉结果。
>
> 用代码复现各步骤的写法见 [automation-stack.md](automation-stack.md)。

## 1. 设置图纸尺寸

`格式 → 绘图细节（Plot Details）→ 打印/尺寸`
- 宽度(W) = **7**，高度(H) = **5**
- 单位(U) = **英寸**

> 原文把这张图称为「7cm×5cm 的点线图」，但对话框中填的是宽度 7、高度 5、单位英寸。
> 照对话框数值执行；若目标期刊明确要求 7 cm × 5 cm 版面，需把单位改成「厘米」并确认字号缩放，
> 这一处遇到时向用户确认一次。

## 2. 设置轴线

`坐标轴 → 轴线与刻度线`
- 颜色：**黑**，粗细 = **0.2**，轴位置 = 左轴/下轴
- 主刻度样式 = **朝内**，次刻度样式 = **朝内**
- 长度、颜色、粗细：主/次刻度都留 **自动**

截图：`assets/origin-02-axis-ticks.png`

## 3. 设置字体

- 中文 = **宋体**；西文 = **Times New Roman（罗马字体）**
- **变量斜体**（如 σ、t 等符号用斜体；单位正体）
- 字号：**标题 26，其余 22**

截图：`assets/origin-03-font.png`

## 4. 调整刻度

- 让坐标轴**两端都有刻度数字**（不要出现一端悬空没有刻度值），例如 x 轴 1.0 / 1.5 / 2.0 / 2.5 / 3.0。
- 刻度**疏密得当**：不要过密堆叠，也不要稀疏到看不出趋势。

截图：`assets/origin-04-tick-labels.png`

## 5. 调整布局

- 图尽量**布满图纸**，不要把曲线挤在中间一小块、四周留大片白。
- 需要时用 `图 → 调整页面至图层大小 / 调整图层至页面大小` 收紧边距。
- 图层/坐标轴区域与页面边框保持匀称的留白（图例、轴标题不被裁切）。

截图：`assets/origin-05-layout.png`

## 6. 调整线条，突出重点

- 按"谁重要谁显眼"分配线条：主对比关系用更粗的线 + 强调色。
- 参考实例：`理论值` 用**红色实线**，`监测值` 用**黑色方块点**；坐标轴与图例框保持黑色细线。
- 图例放在图内空白处，边框细黑线，字号同正文。

截图：`assets/origin-06-line-emphasis.png`

## 7. 导出为图片

- 用 `复制图形为图片`（Copy Graph as Image）或 `导出图形`。
- 曲线类图优先导出**矢量（PDF / EMF / SVG）**或高分辨率位图（≥600 dpi）；
  严格按 600×600 位图交付时，导出后再核对像素与文字清晰度。

截图：`assets/origin-07-export.png`
