# 正斜体与排版细则（中文期刊通用）

本文件是 [origin-format.md](origin-format.md) / [visio-format.md](visio-format.md) 的**补充硬约束**，
适用于所有正文插图与公式。与两份格式文件冲突时，以本文件为准。

---

## 一、物理符号的正体与斜体规定

| 符号类型 | 字体要求 | 示例 |
|---|---|---|
| 物理量符号 | **斜体** | *E*, *σ*, *ε*, *p*, *N*, *D* |
| 希腊字母表示的物理量 | **斜体** | *α*, *β*, *λ*, *ν*, *φ* |
| 数学变量 | **斜体** | *x*, *y*, *z*, *t*, *i*, *j* |
| 计量单位 | **正体** | MPa, GPa, mm, s |
| 数字 | **正体** | 1, 2, 100, 1000 |
| 数学运算函数名称 | **正体** | sin, cos, ln, exp, max |
| 微分符号 | **正体** | d*x*, d*t* |
| 说明性上下标 | **正体** | *p*<sub>max</sub>, *N*<sub>f</sub> |
| 变量性质的上下标 | **斜体** | *a*<sub>*i*</sub>, *σ*<sub>*ij*</sub> |
| 向量、矩阵和张量 | **加粗斜体** | **u**, **K**, ***σ*** |

**一句话记法**：看它是"量"还是"名"。是**量**（变量、物理量、希腊字母）→ 斜体；
是**名**（单位、数字、函数名、说明性下标）→ 正体。

---

## 二、坐标轴标题的写法

1. **量与单位之间用斜杠 `/` 分隔，不用括号。**
   - ✅ `贮室温升 / ℃`、`温差变化率 η / %`、`应力 σ / MPa`、`时间 t / min`
   - ❌ `贮室温升（℃）`、`贮室温升 (℃)`、`应力 σ(MPa)`
   - 斜杠紧跟前后的量名与单位之间各有一个空格（按目标期刊要求微调，但**全文统一**）。
   - **全篇一致**：不能有的图用括号、有的图用斜杠。
2. **单位正体，物理量符号斜体**（见上表）。`η`、`σ`、`t`、`ε` 都是斜体。
3. **坐标轴文字不能过小**。刻度数字与轴标题要在最终印刷尺寸下清晰可读；
   缩到期刊栏宽后若明显偏小，就是不合格，必须放大后重出图。

---

## 三、图中不放解释性文字

**图里只放数据与必要的图例、轴标。** 说明性、定义性的内容一律**移到正文**，图中不解释。

- ❌ 图内或图下写「注：温度测点位于中心气囊外表面，测得温度反映储气空间气体温度。Δ*T*<sub>eff</sub>
  为稳定阶段第 50 次循环内，单次循环最高与最低气体温度之差。」
- ✅ 这段话写进正文正文段落；**物理量首次出现时在正文里解释一次**即可，后续直接使用。
- 图题（图名）下的说明文字同样从简；定义、口径、测点位置这类内容归正文。

---

## 四、物理量的全文统一

**同一个物理量，全文只能有一种写法。**

- 首次出现时在正文里定义/解释一次，之后保持一致。
- **上下标形式必须统一**：若某量规范上用下标（如 Δ*T*<sub>eff</sub>），则**全文所有图、所有公式、
  所有正文都带下标**；不能这张图是下标、那张图不是。
- 同一物理量在不同图里的字体（斜/正）、大小写、上下标写法都必须一致。
- 出图前先建一张"符号对照表"，全篇按表执行。

---

## 五、公式（MathType）

1. **公式字号必须与正文一致。** MathType 有自己的字号设置（`大小 → 定义尺寸`），
   整篇的公式尺寸要设成与正文字号匹配，不能默认沿用旧模板。
   出图/排版后要逐个核对，不要只改一处。
2. **修改过的公式必须标红**，与文中其他修改保持一致，供审稿人比对。
3. 公式中的变量斜体、单位正体、说明性下标正体，按第一节的表执行。

---

## 六、图片与图题之间不留大空白

- 图片底部到"图 X …"图题之间的间距**统一且紧凑**，不得出现明显空隙。
- 常见成因：图片本身带了多余的上下白边（导出时未裁紧），或段落间距/行距设置不一致。
- 出图时把画布裁到内容边界；排版时统一图题段落的段前距与行距。
