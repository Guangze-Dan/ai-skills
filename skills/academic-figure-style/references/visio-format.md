# Visio 论文出图格式（CAD → dxf → Visio，以 8cm 图幅为例）

来源：用户提供的 `visio论文出图格式.docx`。用于**示意图**（结构/剖面/装置/流程/机理线框图），
不是数据图 —— 数据图走 [origin-format.md](origin-format.md)。

对应截图：`assets/visio-01-cad-drawing.png` … `assets/visio-04-convert-to-visio.png`。

## 1. CAD 文件绘制，另存为 dxf

- 在 AutoCAD 里画好线框图，另存为 **dxf**。
- 另存类型选 **AutoCAD 2000/LT2000 DXF (*.dxf)**（兼容性最好）。

截图：`assets/visio-02-dxf-save.png`

## 2. CAD 文件导入 Visio

- `插入 → CAD 绘图`，在弹出的 **CAD 绘图属性** 对话框里设置：
  - CAD 绘图比例：选 **自定义比例(C)**，原文填 `1 mm = 1.8903428283 mm`
    （即先把 CAD 图缩到目标图幅，导入后再微调；按实际图纸算，不必照抄这个数）
  - **取消勾选「锁定大小和位置(L)」**，方便后续调整
- 注意默认页面尺寸可能是 604.6 mm × 297 mm，导入后要按第 3 步重设图幅。

截图：`assets/visio-03-cad-import-scale.png`

## 3. 设置图幅，以 8 cm 为例

- 页面设置里把图幅设为 **8 cm**（单栏宽度常用值）。
- 目标是：图幅尺寸 = 期刊栏宽，文字在 8 cm 宽度下仍是 **9 磅**，也就是最终印刷尺寸下可读。

## 4. 转换成 Visio 对象

- 右键 CAD 图形 → `CAD 绘图对象 → 转换(C)...`，把 CAD 对象转为原生 Visio 形状。
- 转换后才能逐条改线宽、线型、颜色。

截图：`assets/visio-04-convert-to-visio.png`

## 5. 线条、文字、公式

**线条颜色**
- 一般线条 **黑色**；需要强调的用 **红色等亮色**。

**线宽（磅）——按重要性分级，直接照用**

| 用途 | 线宽 |
|---|---|
| 辅助线条 | 0.25 |
| 一般线条 | 0.5 |
| 重要线条 | 1 |
| 特别重要 | 2 |

**线型**
- 辅助线条用 **虚线**。
- 箭头样式用 **13 号**，箭头大小用 **小** 或 **中等**。

**文字**
- 中文 **宋体**，西文 **Times New Roman（罗马）**，**9 磅**。

**公式**
- 用 **MathType** 打，字号 **9 磅**，与正文一致。

## 6. 保存为图片

- **框选**需要导出的区域（不要整页导出，避免大片空白）。
- 另存为 **600 × 600 的 jpg**。
- 导出后核对：线宽在 600×600 下是否仍可分辨（0.25 磅细线最容易丢失），文字是否清晰。
